## 与 Game Dev Pro Max 的关联

Game Dev Pro Max 目前已经覆盖了这本书中大量原则的**实践应用版本**：

| 书中原则 | Skill 中对应内容 |
|---|---|
| **Core Gameplay Loop** | Phase 2 核心玩法循环 — 核心概念+代码实现 |
| **Scope** | Phase 0 选游戏 + 10个陷阱: Scope creep |
| **Flow** | 难度曲线设计 |
| **Playtesting** | Phase 5 测试迭代 |
| **Iteration** | 整个 Phase 5 的核心理念 |
| **Prototyping / Paper Prototyping** | Phase 2 先做能玩的版本 |
| **Risk vs. Reward** | 胜负条件/积分设计 |
| **Fairness** | 碰撞检测、物理规则一致性 |
| **Feedback Loops** | 得分显示、碰撞反馈 |
| **Reward Schedules** | 每帧得分、关卡进度 |
| **Quick Start** | HTML Canvas 50行启动模板 |
| **Game Pillars** | Game Design One-Pager 模板 |
| **Motivation** | 核心理念: 完成比完美重要 |
| **State Machines** | 代码示例: 游戏状态机 |
| **Flow** | 从简单到复杂的难度递进 |
| **Cognitive Biases** | 10个陷阱中的完美主义、需求膨胀 |
| **Skinner Box** | 得分系统设计 |
